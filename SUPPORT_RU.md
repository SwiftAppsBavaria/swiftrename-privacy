# SwiftRename — Поддержка

SwiftRename — это приложение для macOS для пакетного переименования, копирования и перемещения файлов. Фотографии и видео получают имена по дате съёмки (EXIF) и, при желании, автоматически раскладываются по папкам — по годам, месяцам или дням; либо приложение нумерует файлы последовательно с вашим собственным префиксом, либо сохраняет имена и только раскладывает файлы по папкам. Дубликаты определяются по размеру и содержимому и пропускаются.

## Справка в приложении

SwiftRename поставляется с полным встроенным руководством. Откройте его из меню «Справка» или сочетанием ⌘/ (Command-косая черта). В нём описаны все режимы переименования, структуры папок, обнаружение дубликатов и остальные параметры.

## Часто задаваемые вопросы

**Мои фотографии не получают дату съёмки.**
Убедитесь, что включён параметр «Использовать дату камеры». Если у файла нет даты съёмки EXIF, SwiftRename использует вместо неё дату создания.

**Почему некоторые файлы были пропущены?**
Скорее всего, обнаружение дубликатов распознало их как уже существующие (тот же размер и то же содержимое в папке назначения). В диалоговом окне оба файла показаны рядом; вы также можете отключить проверку с помощью параметра «Проверять на дубликаты».

**Можно ли отменить операцию переименования?**
Да — сразу после выполнения нажмите ⌘Z (Правка → Отменить). Скопированные файлы перемещаются в Корзину; перемещённые файлы возвращаются туда, откуда они были взяты.

**Как изменить язык приложения?**
macOS позволяет выбрать язык для каждого приложения отдельно: Системные настройки → Основные → Язык и регион → раздел «Программы». Добавьте туда SwiftRename и выберите нужный язык.
