# SwiftRename — Support

O SwiftRename é um app de macOS para renomear, copiar e mover arquivos em lote. As fotos e os vídeos recebem como nome sua data de captura (EXIF) e, se você quiser, são organizados automaticamente em pastas por ano, mês ou dia; como alternativa, o app numera os arquivos de forma sequencial com o seu próprio prefixo, ou mantém os nomes e apenas os organiza em pastas. Os duplicados são detectados por tamanho e conteúdo e são ignorados.

## Help in the app

O SwiftRename inclui um manual completo integrado. Você o abre pelo menu Ajuda ou com ⌘/ (Comando–Barra). Ele explica todos os modos de renomeação, as estruturas de pastas, a detecção de duplicados e as demais opções.

## Frequently asked questions

**Minhas fotos não recebem a data de captura.**
Verifique se a opção "Usar data da câmera" está ativada. Se um arquivo não tiver data de captura EXIF, o SwiftRename usa a data de criação dele.

**Por que alguns arquivos foram ignorados?**
O mais provável é que a detecção de duplicados os tenha reconhecido como já existentes (mesmo tamanho e mesmo conteúdo na pasta de destino). O diálogo mostra os dois arquivos lado a lado; você também pode desativar a verificação com "Verificar duplicados".

**Posso desfazer uma renomeação?**
Sim — logo após a operação, pressione ⌘Z (Editar → Desfazer). Os arquivos copiados vão para o Lixo; os arquivos movidos voltam para o local de origem.

**Como altero o idioma do app?**
O macOS permite escolher um idioma por app: Ajustes do Sistema → Geral → Idioma e Região → seção "Apps". Adicione o SwiftRename ali e escolha o idioma desejado.
